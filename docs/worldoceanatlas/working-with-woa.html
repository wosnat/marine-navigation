Working with WOA23 in this project

Files are downloaded once into data/raw/woa23/ (ignored by git) and opened with xarray. The helper module src/marine_navigation/woa.py handles URLs, file names and caching.

Setup

uv sync                 # create .venv with xarray, netCDF4, cartopy, cmocean …
uv run jupyter lab      # notebooks
uv run python scripts/make_woa_overview_figures.py   # regenerate the gallery

Opening a file

from marine_navigation import woa

# annual (period "00") temperature, 1955–2022 average, 1° grid
ds = woa.open_woa("temperature", period="00")
ds = ds.isel(time=0)          # every file has a single time step; drop it

sst = ds["t_an"].sel(depth=0)  # objectively analyzed mean at the surface
sst.plot()

Other examples:

woa.open_woa("salinity", period="15")             # Jul–Sep salinity
woa.open_woa("oxygen",   period="07")             # July oxygen (uses the "all" span)
woa.open_woa("temperature", span="B5C2")          # 2015–2022 annual temperature
woa.open_woa("temperature", grid="04")            # quarter-degree (large: ~1.1 GB)
woa.url("nitrate")                                # just get the URL

Without the helper, plain xarray works the same way:

import xarray as xr
ds = xr.open_dataset("data/raw/woa23/woa23_decav_t00_01.nc", decode_times=False)

Reading remotely without downloading (OPeNDAP)

NCEI also serves the files through THREDDS, so you can read just a slice over the network. This is handy for quarter-degree files:

url = ("https://www.ncei.noaa.gov/thredds-ocean/dodsC/woa23/DATA/"
       "temperature/netcdf/decav/0.25/woa23_decav_t00_04.nc")
ds = xr.open_dataset(url, decode_times=False)
gulf_stream = ds.t_an.isel(time=0).sel(lat=slice(30, 45), lon=slice(-80, -50), depth=0).load()

Common operations

# a vertical profile at a point (grid cells are centered on .5 degrees)
prof = ds.t_an.sel(lat=31.5, lon=-64.5, method="nearest")

# a north–south section along a meridian
section = ds.t_an.sel(lon=-25.5, method="nearest")

# a regional box (lat and lon are ascending, so slice low→high)
box = ds.t_an.sel(lat=slice(20, 50), lon=slice(-80, -10))

# surface temperature in July minus the annual mean
july = woa.open_woa("temperature", period="07").isel(time=0)
anom = july.t_ma.sel(depth=0)          # already provided as the _ma field

# an area-weighted global mean (cells shrink toward the poles)
import numpy as np
w = np.cos(np.deg2rad(ds.lat))
global_mean_sst = ds.t_an.sel(depth=0).weighted(w).mean(("lat", "lon"))

# 0–360 longitudes, e.g. for maps centered on the Pacific
ds360 = ds.assign_coords(lon=ds.lon % 360).sortby("lon")

Pitfalls

  • Time does not decode. Time is stored as "months since …", which xarray cannot decode with a standard calendar. Always pass decode_times=False; the helper does this for you.
  • Gap-filled ≠ measured. _an has a value everywhere in the ocean, including places with zero observations (much of the Southern Ocean and the deep ocean, especially for oxygen and nutrients). Check _dd or _sea before trusting fine detail.
  • Smoothing weakens fronts. The objective analysis spreads data over a radius of hundreds of kilometres, so sharp fronts (such as the Gulf Stream wall) look wider and gentler than in reality. Gradients computed from WOA are lower bounds. Use the ¼° grid for T and S when gradients matter.
  • Depth is selected in metres, not by level number: .sel(depth=200). Levels are not evenly spaced, so use method="nearest" or interpolate for other depths.
  • Monthly and seasonal files are shallower (1,500 m for T, S and O2 monthly; 800 m for nutrients). Asking for 3,000 m in a monthly file raises a KeyError.
  • Seasons are named for the northern hemisphere. Period 13 (Jan–Mar) is southern summer.
  • Units: oxygen and nutrients are in µmol/kg, not µmol/L or mL/L. To convert oxygen, 1 mL/L ≈ 44.66 µmol/L.
  • Different time spans per variable: T and S use decav; O2 and nutrients use all (1965–2022).
  • Salinity has no units (PSS-78). Density and other TEOS-10 quantities need the gsw package.

Citation

When using WOA23 data, cite the relevant volume(s), for example Locarnini et al. (2024) for temperature. The full list is on the overview page.
